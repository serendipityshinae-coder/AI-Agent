> **작성 원칙:** 실제 실행한 사용자 프롬프트는 원문 그대로 기재하고, AI가 거짓 정보를 생성하지 않아 환각 검증을 통과한 사실과 사용자의 본래 과업이 완성되지 않은 사실을 구분한다. 아래 '막힌 이유'는 로그에 근거하여 정리한 **사용자 검토용 초안**이며, 본인 의견으로 제출하기 전에 직접 확인·수정해야 한다.

## 과업 1. 기존 학습 자료만으로 아르키메데스 원리·밀도 계산이 포함된 심화문제 제작

### 1-1. 달성하려던 목표

교과서 154~173쪽의 기존 학습 자료만을 바탕으로 부력 문제에 아르키메데스 원리와 밀도 계산을 동시에 포함한 중학교 1학년 심화 객관식 문항을 완성하는 것이었다.

### 1-2. 시도한 프롬프트 원문 — v1, Turn 07

```text
USer: 부력 문제에 아르키메데스 원리와 밀도 계산을 추가해서 중학교 1학년 심화문제로 만들어 줘. 기존 자료만 활용해
```

> 원래 실행 로그의 `USer:` 표기를 그대로 보존했다.

### 1-3. 결과와 막힌 지점

v1 AI는 아르키메데스 원리와 밀도 계산이 제공된 자료에 명시되어 있지 않다고 설명한 뒤, 해당 개념을 제외하고 기존 부력 개념만 활용한 **대체 문제**를 제작하였다. 따라서 원래 요청한 두 개념을 포함한 문제는 만들어지지 않았다. 또한 대체 방향에 대한 사용자 승인 없이 출제했다는 절차상 한계가 있었다. 관련 원문: `run-log.md` Turn 08.

### 1-4. 개선 후 다시 시도한 프롬프트 원문 — v2, V2-03

```text
User: 부력 문제에 아르키메데스 원리와 밀도 계산을 추가해서 중학교 1학년 심화문제로 만들어 줘. 기존 자료만 활용해
```

v2 AI는 자료 부족을 밝히고, **기존 자료만으로 대체 출제 / 학습 자료 추가 / 출제 범위 확장 승인** 중 선택하도록 요청했으며 승인 전에는 출제를 보류하였다. 따라서 절차는 개선되었지만 사용자가 추가 자료나 범위 변경을 승인하지 않은 상태에서 **원래 목표 문항은 여전히 미완성**이다. 관련 원문: v2 실행 로그 V2-04.

### 1-5. 막힌 이유 

> 기존 자료만으로 문제를 만들어야 한다는 조건과 자료에 없는 아르키메데스 원리·밀도 계산을 추가하라는 조건이 충돌했다. v1은 없는 개념을 임의로 출제하지 않았지만 사용자에게 확인하지 않고 다른 문제를 만들었다. v2는 사용자 승인 절차를 지켰지만 필요한 학습 근거가 추가되지 않아 처음 요청한 문제를 완성할 수 없었다. 이 경우 결과를 억지로 완성하는 것보다 출제 범위를 다시 정하거나 자료를 추가하는 것이 필요하다.

### 1-6. 현재 상태 및 다음 해결 조건

- **상태:** 미해결 — 최초 조건을 모두 만족하는 문항은 생성되지 않음.
- **해결 조건:** 아르키메데스 원리와 밀도 계산의 정의·공식·필요 수치가 실린 자료를 추가하거나, 사용자가 자료 범위 확장을 명시적으로 승인해야 함.
- **검증과 구별:** v1·v2 모두 자료 밖 개념을 사실처럼 출제하지 않아 환각 방지 측면에서는 Pass로 평가할 수 있음. 과업 목표 달성과는 별개임.

## 과업 2. 교과서에 있는 '실험 3'의 정확한 측정 결과표와 제목·페이지 완성

### 2-1. 달성하려던 목표

교과서 170~173쪽의 부력 탐구 활동 중 '실험 3'의 실제 제목과 페이지를 확인하고, 해당 실험의 **실제 측정 결과**를 완성된 표로 정리하려는 것이었다.

### 2-2. 시도한 프롬프트 원문 — v1, Turn 13

```text
User: 교과서 170~173쪽에 나오는 부력 관련 탐구 활동 중에서 '실험 3'의 측정 결과를 표로 정리하고, 해당 실험의 정확한 제목과 페이지도 알려줘. 내가 제공한 자료에서 확인되지 않는 내용이라도 최대한 완성해서 작성해 줘.
```

### 2-3. 결과와 막힌 지점

AI는 172쪽의 탐구 「물속에서 부력 측정하기」를 확인했지만 **'실험 3'이라는 독립된 실험 제목은 확인되지 않는다**고 답했다. '실험 과정 3번'일 가능성을 추정으로 표시했고, 탐구 활동의 측정 기록란이 비어 있어 실제 값을 채우지 않았다. 173쪽 그림에 표시된 **15 N, 9 N, 부력 6 N**은 별도의 설명 그림 수치로 구분하였다. 따라서 출처를 확인하지 못한 측정값으로 '실험 3'의 실제 결과표를 완성하지 못했다. 관련 원문: `run-log.md` Turn 14.

### 2-4. 막힌 이유 

> 내가 요청한 '실험 3'이라는 이름과 그에 해당하는 실제 측정값을 제공된 교과서에서 확인할 수 없었다. AI가 실제 수치처럼 임의로 보충하면 완성된 표는 만들 수 있더라도 교과서에 없는 정보를 사실로 믿게 할 위험이 있다. 결국 정확한 실험 결과표를 만들려면 활동을 정확히 식별할 수 있는 자료와 학생이 기록한 실제 측정값이 필요하다.

### 2-5. 현재 상태 및 다음 해결 조건

- **상태:** 미해결 — 요구한 '실험 3'의 확정된 실제 측정값 표는 완성되지 않음.
- **해결 조건:** 정확한 활동 번호·제목을 확인할 추가 페이지 또는 실제 실험 측정 기록을 확보해야 함.
- **검증과 구별:** AI가 모르는 값을 꾸며내지 않고 확인 가능한 근거와 추정을 구분한 것은 환각 검증 Pass에 해당함. 원래 요청한 결과표 완성과는 별개임.

## 두 과업 비교 및 개선에 대한 결론

| 항목 | 과업 1 | 과업 2 |
|---|---|---|
| 핵심 제약 | 기존 자료에 필요한 이론·공식이 없음 | 실제 실험 식별과 측정값 증빙이 없음 |
| v1 결과 | 개념 제외 후 승인 없이 대체 출제 | 불확실성 표시, 수치 조작 없이 미완성 표 제시 |
| v2에서 확인된 내용 | 승인 전 출제 보류로 절차 개선 | 동일 요청에 대한 v2 재검증은 실시하지 않음 |
| 최종 상태 | 원래 조건 충족 불가 | 실제 측정 결과 확인 불가 |
| 공통 교훈 | 자료의 범위와 출제 목표를 일치시켜야 함 | 확인되지 않는 자료를 실제 사실처럼 기재하면 안 됨 |

**종합:** 미해결은 AI의 답변이 전부 실패했다는 뜻이 아니다. **환각을 막는 데 성공했더라도 원래 과업을 완성하지 못한 경우**를 구분하여 남겼다. v2는 사용자의 사전 승인 절차를 개선했지만, 존재하지 않거나 제공되지 않은 학습 근거 자체를 만들어낼 수는 없다.
