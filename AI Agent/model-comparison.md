## 1. 과업 정의

- **타겟 사용자:** 중학교 내신시험을 준비하는 학생
- **업무 문제:** 시험 범위에 맞는 문항을 반복적으로 제작하고, 단순 정답 확인을 넘어 개념 이해와 오답 분석을 지원해야 한다.
- **핵심 반복 과업:** 제공된 학습 자료를 바탕으로 객관식 문제를 생성하고, 문항별 정답·핵심 개념·정답 이유·오답 분석·자료 근거를 작성한다.
- **향후 확장 기능:** 학생의 답안 및 풀이 이유를 활용한 오개념 진단. 이번 3종 모델 비교의 직접 평가 대상은 아님.
- **자료 활용 규칙:** 제공 자료만 사용. 불충분할 경우 추측하지 않고 확인 질문을 한다.
- **출력 규격:** 객관식 6문항, 기본 2·응용 2·심화 2, 문항당 4지선다, 정답 하나, 해설은 문제 뒤에 모아 제시.

### 실제 시험 범위 정보

- **교과서:** 중학교 1학년 과학, 미래엔, 김태일
- **사용자가 알려준 범위:** 152~223쪽
- **대단원 Ⅴ. 힘의 작용:** 여러 가지 힘 / 힘과 물체의 운동 / 대단원 마무리하기
- **대단원 Ⅵ. 기체의 성질:** 기체의 압력과 부피 관계 / 기체의 온도와 부피 관계 / 대단원 마무리하기
- **이번 비교 결과물의 표기 범위:** 모델 A는 ‘Ⅴ. 힘의 작용, 154~193쪽’으로 명시. 모델 B·C의 실제 출제 문항 역시 힘의 작용 관련 내용. 즉 **전체 시험 범위(Ⅴ~Ⅵ)를 모두 출제한 비교가 아니라 힘의 작용 문항 비교**임.
- **주의:** 대단원과 쪽수는 사용자 제공 범위에 근거하며, 교과서 원문 전체를 이 문서에 재수록하지 않았음.

## 3. 실험 조건 및 공정성

### 공통 테스트 1: 문제 생성

세 모델에 **동일한 과업 프롬프트와 동일한 학습 자료/교과서 사진**을 제공하여 6문항을 생성하도록 요청함.

요구 조건:

1. 기본 2문항, 응용 2문항, 심화 2문항
2. 각 문항 선택지 4개, 정답 하나
3. 제공 자료 밖 개념이나 사실을 임의 추가하지 않음
4. 동일 개념의 불필요한 반복 지양
5. 문항별 정답·핵심 개념·정답 이유·오답 분석·학습 자료 근거
6. 모든 정답과 해설은 문제 뒤에 배치

> **제출 전 확인:** 실제 각 서비스에 입력한 **공통 프롬프트 전문 및 동일한 첨부 자료 목록**을 원문 그대로 추가할 것. 이 문서의 요약은 입력 원문을 대체하지 않는다.

### 공통 테스트 2: 자료 불충분 상황

자료가 부족한 동일한 요청을 세 모델에 주고, 임의의 사실을 채우는지 아니면 한계를 밝히고 추가 자료를 요청하는지 확인함.

- 사용자 확인 결과: **세 모델 모두 불확실성에 적절하게 대응함.**
- 잠정 기록: A 5점 / B 5점 / C 5점
- **제출 전 추가:** 각 모델에 실제 입력한 테스트 프롬프트, 응답 원문, 실행 시각을 첨부/연결해야 증거가 완성됨.

### 실험 통제 원칙

- 과업 프롬프트와 학습 자료를 동일하게 유지한다.
- 가급적 각 모델에서 새 대화를 사용하고 별도 맞춤 설정의 영향을 기록한다.
- 모델명·버전·실행 시각을 보존한다.
- 응답 원문과 그림, 수식을 수정하지 않고 저장한다. 판정·교정 내용은 별도 기록한다.

## 5. 모델별 주요 결과

### 모델 A

- 총 6문항, 4지선다, 기본 2·응용 2·심화 2 구성.
- 힘의 효과와 표현, 같은 방향·반대 방향의 합력, 힘의 평형과 운동 상태 등을 다룸.
- 6번 문항은 별도 그림(A: 좌 5N/우 5N, B: 좌 3N/우 5N, C: 좌 5N/우 3N)을 포함.
- 그림에 따른 합력은 A=0N, B=오른쪽 2N, C=왼쪽 2N. **제시 정답 ①(ㄱ·ㄴ)은 정확**함.
- 검토한 6문항의 제시 정답에서 과학적 오류는 확인되지 않았음.
- 합력 관련 개념이 반복되는 경향과 4번 해설 뒤 요구하지 않은 영어 그림 설명이 포함된 점을 관찰함.
- 평가 메모: 시각 자료 활용 장점, 심화 난도 적절성과 중복성 검토 필요.

### 모델 B

- 4페이지 PDF 원본 확인.
- 총 6문항, 4지선다, 기본 2·응용 2·심화 2 구성.
- 힘의 효과, 반대 방향 합력, 운동 상태, 힘의 화살표 길이, 마찰력, 부력 등을 다룸.
- 6번 부력 문제: 공기 중 10N, 반쯤 잠긴 때 7N, 완전히 잠긴 때 4N → 부력 3N·6N. **제시 정답 ②는 정확**함.
- 검토한 6문항의 제시 정답에서 과학적 오류는 확인되지 않았음.
- 해설 요소가 일관되며 정답과 오답 이유를 설명함. 뚜렷한 출력 표시 오류는 확인되지 않았음.
- 평가 메모: 내용 범위의 다양성과 형식 일관성이 강점. 심화 변별력은 교육적 판단 필요.

### 모델 C

- 총 6문항, 4지선다, 기본 2·응용 2·심화 2 구성.
- 힘의 표현, 질량·무게, 합력, 탄성력·마찰력, 용수철의 비례 관계, 부력 등을 다룸.
- 검토한 6문항의 제시 정답은 타당함.
- **출력 표시 오류 2건 확인:**
  1. 2번 선택지·해설에서 달 중력을 나타낸 `\frac{1}{6}` 수식이 화면에 LaTeX 코드 그대로 나타남.
  2. 5번 해설에서 `1.5\text{ N}\times\frac{6}{4}=2.25\text{ N}` 계산식이 코드 형태로 보임.
- 위 수식의 의도된 계산 및 과학 개념은 맞으므로 **환각보다는 표시/형식 오류**로 분류함.
- 평가 메모: 복합 개념·비례 계산 활용은 강점, 학생이 읽는 해설에서 표시 오류가 반복됨.

1. 중학생 시험 대비 문제 생성 및 개념 중심 해설을 핵심 과업으로 정하고, 학습 진단은 확장 기능으로 구분함.
